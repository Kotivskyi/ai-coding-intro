# AI Chat Assistant - Client

A modern React-based frontend for the AI Chat Assistant application, built with Vite and Tailwind CSS.

## Features

- 🎨 Modern UI with Tailwind CSS
- 🔄 Real-time chat interface
- 🔐 User authentication (Login/Register)
- 📱 Responsive design
- 🚀 Fast development with Vite
- 🛣️ Client-side routing with React Router

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm (v7 or higher)

### Installation

1. Clone the repository
2. Navigate to the client directory:
   ```bash
   cd client
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Building for Production

Create a production build:
```bash
npm run build
```

The build output will be in the `dist` directory.

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Create production build

## Development Guidelines

### Component Structure

- Use functional components with hooks
- Follow the atomic design pattern
- Keep components small and focused
- Use TypeScript for type safety (planned)

### Styling

- Use Tailwind CSS for styling
- Follow BEM naming convention for custom classes
- Keep styles scoped to components

### State Management

- Use React Context for global state
- Use local state for component-specific state
- Consider Redux for complex state management (if needed)

### Code Quality

- Follow ESLint rules
- Use Prettier for code formatting
- Write unit tests for components
- Document complex logic
